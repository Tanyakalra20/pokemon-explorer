# Pokémon Explorer

This is a React-based application developed as part of the assignment for the **JavaScript Development Internship** at **Madrocket Technologies & Media**.

## Features
- Displays a list of Pokémon.
- Search functionality to find a specific Pokémon.
- Pagination to navigate through a large number of Pokémon.

## Tech Stack
- React.js
- Tailwind CSS
- Axios for API calls
